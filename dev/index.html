01 API Access (Legacy v1)

Sandbox credentials

The legacy sandbox uses API keys instead of the current bearer token flow. Keys are prefixed ts_live_ (despite the name, these are sandbox-only).

curl -H "X-API-Key: ts_live_abc123def456" \
    https://dev.paleon-lab-fintech.co.uk/v1/payments

Deprecated endpoints still served

  • GET /v1/transactions → use /v1/payments
  • POST /v1/transfers → use /v1/payouts
  • GET /v1/balance → use /v1/ledger/trial-balance
  • GET /v1/merchant → use /v1/merchants/me

02 Webhook testing (Legacy)

HMAC-SHA1 (deprecated)

Legacy webhooks use SHA1 signatures. Current API uses HMAC-SHA256 via Tessera-Signature header. This endpoint remains for backwards compatibility only.

# Legacy verification (DO NOT USE FOR NEW INTEGRATIONS)
echo -n "${payload}${timestamp}" | openssl dgst -sha1 -hmac "${secret}"

05 Infrastructure notes

Observability

This legacy environment runs on an older stack. External scanners may observe the following characteristics which are intentionally exposed for testing:

  • HTTP response header Server: nginx/1.14.0 (EOL 2019-10-01)
  • TLS 1.0/1.1 may be negotiated (intentionally not disabled on this host)
  • No HSTS header on this subdomain
  • Legacy cipher suites may be offered

Note: These are configuration-level indicators of outdated components. They do not imply confirmed exploitability. The expected scanner classification is detected/inferred outdated component, not confirmed CVE exploitation.
