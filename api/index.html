03 Authentication

Bearer tokens (sandbox)

All API calls require an Authorization: Bearer header. In the sandbox, any non-empty token is accepted and maps to the demo merchant.

curl -H "Authorization: Bearer test_sandbox_token" \
  https://api.paleon-lab-fintech.co.uk/v1/payments

04 Idempotency

Safe retries

Include an Idempotency-Key header on any write request. The same key within 24h returns the original response — safe to retry on network errors.

curl -X POST -H "Authorization: Bearer test_sandbox_token" \
  -H "Idempotency-Key: unique-key-per-request" \
  -H "Content-Type: application/json" \
  -d '{"amount":1000,"currency":"GBP"}' \
  https://api.paleon-lab-fintech.co.uk/v1/payments

05 Webhook signatures

HMAC-SHA256 verification

Events are signed with a per-endpoint secret. Verify the Tessera-Signature header (timestamp + SHA256) before trusting any event.
