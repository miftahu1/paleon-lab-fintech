02 Reference material

Guides & notes

Idempotency

Send an Idempotency-Key header on any write. The same key returns the same result — safe to retry on network errors.

Webhooks

Events are signed with HMAC-SHA256 over the raw body. Verify the Tessera-Signature header before trusting an event.

Settlement windows

FPS pays in seconds; BACS batches at 10:00 for T+3. Card clears T+1. All times are illustrative in this test environment.

Rate limits

120 requests/minute per token on the sandbox. Limits are published headers: X-RateLimit-Remaining.
